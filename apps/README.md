# Aplicaciones

Este directorio agrupará las aplicaciones desplegables del monorrepositorio:

- `mobile/`: aplicación Android con React Native, Expo, TypeScript y Expo Router. Incluye navegación y un prototipo visual del Sprint 1; todavía no integra operaciones clínicas reales.
- `gateway/`: pasarela para chatbot y funciones asociadas al dispositivo.
- `central-api-simulator/`: simulador local de la API clínica con datos ficticios.

La pasarela y el simulador están previstos para entregas posteriores. La ruta de las escrituras clínicas y la sincronización deberá seguir las decisiones de arquitectura acordadas para el proyecto.
