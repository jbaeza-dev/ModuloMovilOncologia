## 2. Garantía de Aislamiento

El motor de formularios interpreta definiciones versionadas de forma dinámica. Toda decisión clínica documentada arriba se encuentra encapsulada dentro del fixture de demostración (`seguimiento-domiciliario.ts`) y nunca como reglas cableadas en la lógica del motor o los componentes visuales.
